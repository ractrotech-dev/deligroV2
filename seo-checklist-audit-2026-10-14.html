CRITICAL Every public page redirects crawlers to /login (307) SEO
src/proxy.ts:147

Verified live: /, /stores, /search and /restaurant/<slug> all return 307 → /login, including with a Googlebot user-agent. Restaurant pages, their metadata, JSON-LD and the 100+ sitemap URLs are never seen. This covers checklist items 1, 3, 4, 5, 6, 7, 10, 11 and 12 in practice.

Fix

Decision, not a code tweak. Option A: leave as-is (app-only product, SEO not a goal). Option B: let anonymous requests through to the browse-only routes (/, /stores, /search, /restaurant/*) and keep the login gate on checkout/orders/profile. Option B is a behaviour change to the launch flow.
You must do this yourself: Owner decision needed. Delivery phase is 'no new features', so this should not be changed without explicit approval.
MEDIUM The one page crawlers can fetch (/login) is indexable but robots.txt blocks it SEO
src/app/layout.tsx:58, src/app/robots.ts:41

/login serves the site-wide title/description with robots 'index, follow', has no canonical, and is Disallowed in robots.txt. Contradictory signals; Google may show it as a URL-only result.

Fix

Add to src/app/login/layout.tsx:
export const metadata = { robots: { index: false, follow: true } };
(or remove /login from the Disallow list if it should be the landing page).
MEDIUM Home page has no <h1> (h2 only) SEO
src/components/home/home-view.tsx:169

The storefront heading hierarchy starts at h2. Matters only once the storefront is publicly reachable.

Fix

Add one visually-hidden or visible <h1> to the home view (copy in English; no Hindi added).
LOW og:image is a 512×512 app icon, not a 1200×630 share image SEO
src/app/layout.tsx:52

WhatsApp/Facebook previews of the site root show a small logo. Restaurant pages already use their own photo, which is fine.

Fix

Supply /og-default.png at 1200×630 and reference it; twitter card to summary_large_image.
LOW No canonical, schema or metadata on home, /stores, /search SEO
src/app/(customer)/page.tsx, stores/page.tsx, search/page.tsx

Only restaurant and about pages set canonical. No Organization/WebSite/LocalBusiness JSON-LD for the brand itself.

Fix

Add alternates.canonical and a page title to each; one Organization JSON-LD on the home page.
